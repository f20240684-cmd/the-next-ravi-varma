# `data/` -- dataset layout

```
data/
├── raw/          # your source images go here (any subfolder structure)
├── processed/    # generated by scripts/prepare_dataset.py -- resized/cropped JPEGs + manifest.jsonl
├── captions/     # generated by scripts/generate_captions.py -- one <stem>.json per image
├── metadata/     # metadata.jsonl (you provide or scripts/download_dataset.py generates) + validation_report.json
└── reference/    # a small held-out set of real Ravi Varma images, used ONLY for style-similarity evaluation (never for training)
```

## `metadata/metadata.jsonl` schema

One JSON object per line:

```json
{"image": "0001.jpg", "caption": "A royal Indian woman in traditional attire, oil painting texture", "artist": "Raja Ravi Varma", "source": "Wikimedia Commons, public domain", "year": null, "title": null}
```

- `image` (required): path relative to `data/raw/`.
- `caption` (optional): if omitted, `scripts/generate_captions.py --write-metadata` will fill it in.
- `artist`, `source`, `year`, `title`: optional provenance fields, strongly recommended for anything you plan to share.

## Where to get images

1. **`scripts/download_dataset.py`** pulls public-domain reproductions of Ravi Varma's paintings
   from the Wikimedia Commons category `Category:Paintings by Raja Ravi Varma`, along with
   license/attribution metadata, via the official MediaWiki API. Raja Ravi Varma died in 1906, so
   his original works are public domain; Commons hosts licensed digital reproductions.
2. **Your own images.** Drop licensed or public-domain images directly into `data/raw/` and add a
   matching line to `metadata.jsonl`. Do not scrape or bulk-download from arbitrary websites --
   only use sources whose license you can verify and record.

## Reference corpus (`data/reference/`)

A handful (10-30) of real Ravi Varma images kept *out* of the training set, used only for the
style-similarity metric in `scripts/evaluate.py`. Populate it the same way as `raw/`.

## Running validation

```bash
python scripts/validate_dataset.py
```

Checks: corrupt images, missing images, unsupported formats, exact + near-duplicates, minimum
resolution, missing captions, invalid metadata JSON. Writes a full report to
`data/metadata/validation_report.json`.
